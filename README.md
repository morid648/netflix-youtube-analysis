# Netflix India YouTube Content Analysis

## Overview
This project analyzes the performance of Netflix India’s YouTube content using Exploratory Data Analysis and Power BI.
The goal was to identify what type of content drives higher engagement and scalable view growth.
The analysis focuses on video metadata, publishing patterns, and performance distribution.
It is built to support content strategy decisions with simple and business-focused insights.

## Business Problem
Netflix India publishes different types of content on YouTube, but not every upload performs equally.
The key question is: which content patterns are actually driving views and engagement?
This project helps identify repeatable content structures instead of relying only on upload volume.

## Key Insights
- Around 20% of uploads generated nearly 90% of total views.
- Long-form content contributed 91.69% of total views.
- Shorts contributed 8.31% of total views.
- Videos in the 1–5 minute range showed the strongest average performance.
- Moderate tag usage performed better than excessive tagging.
- Longer titles outperformed shorter titles.
- Morning and afternoon uploads performed better than late-night uploads.
- Strong performance came from repeatable high-performing structures, not upload frequency alone.

## What I Did
- Cleaned and validated the dataset.
- Standardized duration values for better comparison.
- Created calculated columns such as TagsCount and content Category.
- Performed metadata analysis on titles, tags, publishing time, and duration.
- Conducted Exploratory Data Analysis to find content-performance trends.
- Built KPI-based analysis to measure views, likes, comments, and content distribution.
- Designed a Power BI dashboard to present insights in a simple business format.
