# Analysis Methodology

## Project Objective

The purpose of this project was to analyze Netflix India’s YouTube channel performance using Exploratory Data Analysis (EDA) and Business Intelligence techniques.

The project focused on identifying scalable content-performance trends using metadata and engagement analysis.

---

# Workflow

## 1. Data Collection

The dataset was provided through the Codebasics Data Analytics Bootcamp – Codebasics Virtual Internship.

### Dataset Fields

- video_id
- title
- description
- tags
- publishedAt
- viewCount
- likeCount
- commentCount
- duration

---

## 2. Data Cleaning & Validation

The dataset was cleaned and standardized before analysis.

### Steps Performed

- Checked for missing values
- Standardized duration formats
- Validated engagement-related fields
- Cleaned metadata inconsistencies

---

## 3. Feature Engineering

Additional calculated columns were created to support analysis.

### Calculated Columns

#### TagsCount
Calculated the number of tags used in each video.

#### Duration Category
Videos were categorized into:
- Short-form
- Long-form

#### Standardized Duration
Video durations were converted into a consistent format for comparison.

---

## 4. Exploratory Data Analysis (EDA)

EDA was performed to identify performance trends and engagement patterns.

### Analysis Areas

- Views distribution
- Engagement trends
- Metadata impact
- Upload timing analysis
- Content format comparison
- Duration-performance relationship

---

## 5. KPI Analysis

Key performance indicators were analyzed to evaluate content efficiency.

### KPIs Used

- Total Views
- Likes
- Comments
- Average Performance by Duration
- Performance by Upload Timing
- Performance by Metadata Structure

---

## 6. Dashboard Development

Interactive dashboards were created in Power BI.

### Dashboard Goals

- Simplify business storytelling
- Highlight scalable trends
- Improve insight readability
- Support decision-making analysis

---
