# Project Summary

## Project Title

Netflix India YouTube Performance Analysis

---

## Overview

This project analyzes Netflix India’s YouTube channel performance using Exploratory Data Analysis (EDA) and Business Intelligence techniques.

The objective was to identify repeatable content-performance trends using engagement metrics, metadata analysis, and publishing behavior.

The project combines business-focused analytics with dashboard storytelling to understand what drives scalable audience engagement.

---

# Business Problem

Content platforms publish large amounts of videos, but only a limited number generate strong audience engagement.

This project aimed to answer:

- Which content formats perform best?
- Does metadata influence performance?
- Does publishing timing impact engagement?
- Are scalable performance patterns visible?

---

# Key Findings

- Approximately 20% of uploads generated nearly 90% of total views
- Long-form content generated approximately 91.69% of views
- Shorts generated approximately 8.31% of views
- 1–5 minute videos showed the strongest average performance
- Moderate tag counts outperformed excessive tagging
- Longer titles generally performed better
- Morning and afternoon uploads outperformed late-night uploads

---

# Business Recommendations

Based on the analysis, the following strategies appear most effective:

- Prioritize long-form content
- Focus on mid-length high-engagement formats
- Optimize upload timing
- Improve metadata quality instead of quantity
- Build repeatable high-performing content structures
- Continue franchise/show-level analysis
